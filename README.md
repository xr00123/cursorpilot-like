# cursorpilot-like

一个轻量级鼠标点击特效/叠层工具（CursorPilot 风格），专为 Windows 优化。

## 快速开始

### 方式一：一键运行（推荐）
直接双击运行目录下的 `run.bat` 文件。
它会自动安装依赖并启动设置界面。

### 方式二：命令行手动运行

1. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

2. **启动程序**
   - 带设置面板（推荐）：
     ```bash
     python main.py
     ```
   - 仅后台运行：
     ```bash
     python click_animator.py
     ```
